## Rust Pixel Bridge 0.5.1

The first downloadable Windows release brings the native conversation panel and MCP bridge to Aseprite.

- Connect Codex through the official client or choose a tool-capable OpenRouter model.
- Create and edit sprites, layers, frames and palettes.
- Attach a reference image alongside the current sprite, with thumbnails and image-capability checks.
- Use Agent or read-only Ask mode, local history, cancellation and Aseprite's undo.
- Keep the panel anchored to the right or switch to a floating window.

This patch corrects automated installer validation of the Start Menu shortcut folder. Package publication requires the installation and uninstallation test to pass.

### Installation

Download **RustPixelBridge-0.5.1-windows-x64-Setup.exe**, run it and restart Aseprite. The ZIP includes a manual installer. Aseprite must be installed separately.

Windows packages are unsigned. Verify their SHA-256 hashes against `SHA256SUMS.txt`. The panel is an overlay rather than a docked editor column, and its UI is currently in Portuguese.

These packages are built on GitHub-hosted runners. No personal artwork, credentials, conversations or diagnostic logs are included.
